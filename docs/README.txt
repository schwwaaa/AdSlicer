AdSlicer Help Website

Open index.html in a browser or publish this directory as the repository documentation site.

Includes:
- Installation: compiled releases or source builds
- Quick Start and output reference
- Tips & Tricks and archival use cases
- Full parameter, preset, tuning, ML, and build documentation
- Complete File, Edit, View, Go, and Help pull-down navigation
- Back, forward, previous-topic, and next-topic navigation
- Optional contents-pane toggle
- Classic About AdSlicer dialog with animated program overview and tagline
- Repository, release-download, and issue-tracker links

Keyboard shortcuts:
- F1: About AdSlicer
- Ctrl/Cmd+G: Open repository
- Ctrl/Cmd+B: Toggle contents pane
- Alt+Left / Alt+Right: Back / Forward
